## 六、明确暂不做（防止范围膨胀）

- 多商户 / 多租户
- 微服务、注册中心、网关、Spring Cloud
- 完整 SKU（除非开始卖多规格实物）
- 数字商品多版本（先一版本一商品）
- 秒杀库存分桶（除非压测出现瓶颈）
- 优惠券/积分体系（除非运营明确需要）
